### :godmode: About Me

I'm a software developer for Desktop/Mobile and backend.

I was worked as a lecturer at the university, engaged in scientific research and teaching, developed educational courses on programming using Assembly language, C, C++, Java.

### 🎓 Conducted Lectures and Practices

* Programming with C language
* Programming with C++ language
* Programming with Java language
* Developing Desktop applications with using Java language
* Code research
* Operating system architecture
* Processor architecture and assembly language programming

### :hammer_and_wrench: Main Skills

* Optimizing code with Assembly language for more speed or less memory
* Developing server and other backends using C or C++
* Developing Desktop software using C/C++ or Java
* Creating a GUI for Desktop with using Qt, WxWidgets, JavaFX
* Developing mini games using SDL, SFML, libGDX and Qt
* Developing Android applications with Java and native code
* Integrating mobile Ads SDK like AdMob, Mintegral, IronSource and others
